# 🤖 Computer Intelligence & Deep Learning Tasks

## 📌 Project Overview
A comprehensive collection of Deep Learning tasks implemented using **PyTorch** and **TensorFlow**, covering Computer Vision and NLP.

## 📂 Projects Included
- **Weekly Tasks:** Implementation of MLP, pytorch, CNN, BERT, NLP Tasks
- **Midterm (Object Detection):** Custom object detection using **YoloV5**.
- **Endterm (Image Classification):** High-accuracy classification using **Google's EfficientNet V2**.
